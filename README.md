# condition-table-system

读取物料平衡表并按模板生成工艺条件表。

## 使用方法

1. 使用近期版本的 Chrome 或 Edge 打开 `index.html`。
2. 选择 `.xlsx` 格式的条件表模板。
3. 选择 `.xls` 或 `.xlsx` 格式的物料平衡表。
4. 可选：选择 `.xls` 或 `.xlsx` 格式的流体一览表，以补充设计温度和压力。
5. 按页面步骤完成识别、关联和参数配置，然后生成并检查结果，下载生成的工作簿。

如果没有选择流体一览表，应用不会补充设计温度和压力。模板的格式要求由应用内的识别与校验提示说明。

## 数据处理

工作簿在浏览器中读取、计算和生成。此项目是没有后端服务的静态页面，业务代码不向服务器上传工作簿；主题偏好保存在当前浏览器的本地存储中。使用 GitHub Pages 等静态托管时，浏览器仍会请求托管网页文件，但工作簿处理在浏览器本地完成。

请勿把真实项目工作簿、客户资料或生成结果提交到代码仓库。

## 依赖

运行时依赖已随 `index.html` 内嵌，无需安装 Node.js、npm 或 Python。第三方组件说明见 [`DEPENDENCIES.md`](DEPENDENCIES.md)。
